# A股/港股均线测算工具

一个纯前端、零依赖的均线测算工具。输入 A 股 6 位代码或港股 5 位代码，即可获取最近 260 个交易日的 K 线数据，
并计算 MA5 / MA10 / MA20（可叠加 MA60 / MA120 / MA250）在**该标的实际涨跌停区间**下的预测收盘价与均线值，辅助短线交易决策。

## 功能特性

- **均线测算** — 基于最近 260 个交易日收盘价，计算 MA5 / MA10 / MA20 / MA60 / MA120 / MA250
- **涨跌幅推演** — 区间由接口提供的涨跌停价自动推导，主板 ±10%、创业板/科创板 ±20%、港股无涨跌停时回退 ±30%；支持 **每 1% / 每 5%** 档位步长切换（5% 时只保留 5 的倍数档位），显示各档对应的预测收盘价及均线值
- **涨跌停价提示** — 状态栏直接显示当日涨停价 / 跌停价（A 股）；港股与退市股等无有效涨跌停时不显示
- **信号摘要卡** — 一句话给出均线排列（多头/空头/交织）、价格与 MA20/MA60 相对位置、最近一次 MA5/MA10 金叉死叉，以及上下方最近关键位
- **K 线图表** — 原生 Canvas 绘制 K 线 + 均线（MA5/10/20/60 默认绘制），叠加支撑/压力位与斐波那契回撤标注（可开关）
- **十字光标** — 鼠标悬停 / 手指拖动时显示该根 K 线的开高低收与各均线值
- **关键位提示** — 自动标注距离目标价最近的关键位，并在 ±0.5% 内高亮提示
- **多格式导出** — 一键复制纯文本 / CSV / Markdown，或直接将 K 线图存为 PNG（无新增依赖）
- **市场状态精准** — 以接口返回的行情时间为准判断盘中/已收盘，避免节假日、非交易日把旧行情误判为盘中；港股含 16:00-16:10 收市竞价
- **双主题** — 亮色 / 暗色主题切换，偏好写入 `localStorage`
- **数据源** — 调用腾讯股票 API（`web.ifzq.gtimg.cn`），无需 API Key
- **本地历史** — 查询记录自动存入 `localStorage`（上限 20 条），下次输入时提供自动补全
- **移动端适配** — 响应式布局，双表在窄屏自动堆叠，宽表横向滚动不撑破页面
- **无障碍** — 完整 ARIA 语义、键盘操作（方向键/Enter/Space/Escape）、可见焦点环、对比度符合 WCAG AA

## 快速开始

1. 直接双击打开 [`stock-ma-tool.html`](stock-ma-tool.html)（或通过本地静态服务器访问，见下）
2. 在输入框中输入代码：A 股 6 位（如 `600519`）、ETF（如 `510300`）、港股 5 位（如 `00700`）
3. 点击 **查询** 按钮
4. 查看均线推演表格与 K 线图，点击表格任意一行可预览该涨跌幅对应的预测价与均线

> **支持范围**
> - 沪市：`6` / `9` / `5` 开头
> - 深市：`0` / `1` / `3` / `4` / `8` 开头（含 ETF `15` / `51` 开头）
> - 港股：5 位数字（接口会补齐为 5 位并加 `hk` 前缀，如 `hk00700`）
> - 若浏览器对跨域请求有额外限制，建议通过本地服务器访问（见「本地运行」）

## 界面说明

| 区域 | 说明 |
|------|------|
| 输入区 | 输入代码，支持历史自动补全与键盘导航 |
| 状态栏 | 显示股票名称、最新价、涨停/跌停价、市场状态（盘中/已收盘）、数据源（均线不在此重复展示） |
| 信号摘要卡 | 均线排列、价格与 MA20/MA60 关系、最近金叉/死叉、上下方最近关键位 |
| 推演表格 | 左表为涨幅档位，右表为跌幅档位，区间由涨跌停自动推导，含预测收盘价、关键位与 MA5/10/20 |
| 档位步长 | 切换推演表格的档位步长（每 1% / 每 5%）；港股等 ±30% 区间用 5% 可把 61 档压缩为 13 档 |
| 标注层开关 | 位于 K 线图标题下方，控制 K 线图上的支撑/压力位、斐波那契回撤、长周期均线（MA120/250）是否显示 |
| K 线图 | 只绘制最近 120 根 K 线（开启长周期均线时 250 根，并按画布宽度自适应，最少 40 根），避免根数过多导致每根不足 1px；右侧预留空间并标注各条均线的最新数值；虚线右侧为预测区域；支持十字光标查看单根 OHLC；点击标题可折叠 |
| 导出按钮 | 复制文本 / 复制 CSV / 复制 Markdown / 导出 PNG 图片 |

## 技术细节

- **数据接口** — 腾讯 K 线 API：`web.ifzq.gtimg.cn/appstock/app/fqkline/get`（前复权日线）
- **均线算法** — 简单移动平均（SMA），取最近 N 日收盘价均值；不足周期返回 `null` 而非误导性数值；逐日均线序列使用滚动求和（O(n)）
- **预测逻辑** — 以「盘中昨收 / 已收盘今收」为基准价施加涨跌幅作为下一交易日收盘价，重新计算 MA5/10/20
- **推演区间** — 由接口的昨收与涨跌停价反推百分比并取整，落在 (0, 30%] 内才采用；否则按市场回退兜底值（A 股 ±10%、港股 ±30%，用于无涨跌停数据的情形）
- **档位步长** — 推演档位默认为每 1% 一档；切换到 5% 时只保留该步长的整数倍档位，便于查看宽区间（如港股 ±30%）
- **图表渲染** — 原生 HTML5 Canvas，`devicePixelRatio` 适配；均线与推演始终使用完整历史计算，绘制时仅裁剪显示窗口（默认最近 120 根，开启长周期均线时 250 根，并按画布宽度自适应）；右侧预留 86px 用于均线末值标签，标签间做防重叠推挤；十字光标按 `chart.view` 换算下标，无第三方图表库
- **导出** — 文本/CSV/Markdown 共用同一份表格数据源，保证三种格式内容一致；PNG 通过 `canvas.toDataURL()` 直接下载
- **网络健壮性** — `AbortController` 8 秒超时取消、同代码请求去重、60 秒结果缓存、过期响应丢弃
- **主题切换** — CSS 变量 + `localStorage` 持久化

## 已知限制

- **北交所**：腾讯 `fqkline` 接口不提供北交所日线数据，`bj` 前缀返回空数组，暂不支持按北交所标的识别
- **港股创业板（GEM）**：部分标的在该接口可能无日线数据返回
