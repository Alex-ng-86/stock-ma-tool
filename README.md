# A股/港股均线测算工具

一个纯前端、零依赖的均线测算工具。输入 A 股 6 位代码或港股 5 位代码，即可获取最近 60 个交易日的 K 线数据，
并计算 MA5 / MA10 / MA20 均线在 **-10% ~ +10%** 涨跌幅区间下的预测收盘价与均线值，辅助短线交易决策。

## 功能特性

- **均线测算** — 基于最近 60 个交易日收盘价，计算 MA5 / MA10 / MA20
- **涨跌幅推演** — 覆盖 -10% 至 +10%（含），每 1% 一档，显示各档对应的预测收盘价及均线值
- **K 线图表** — 原生 Canvas 绘制 K 线 + 三条均线，叠加支撑/压力位与斐波那契回撤标注（可开关）
- **关键位提示** — 自动标注距离目标价最近的关键位，并在 ±0.5% 内高亮提示
- **双主题** — 亮色 / 暗色主题切换，偏好写入 `localStorage`
- **数据源** — 调用腾讯股票 API（`web.ifzq.gtimg.cn`），无需 API Key
- **本地历史** — 查询记录自动存入 `localStorage`（上限 20 条），下次输入时提供自动补全
- **一键复制** — 可将测算结果以纯文本格式复制到剪贴板
- **移动端适配** — 响应式布局，双表在窄屏自动堆叠，宽表横向滚动不撑破页面
- **无障碍** — 完整 ARIA 语义、键盘操作（方向键/Enter/Space/Escape）、可见焦点环、对比度符合 WCAG AA

## 快速开始

1. 直接双击打开 [`stock-ma-tool.html`](stock-ma-tool.html)（或通过本地静态服务器访问，见下）
2. 在输入框中输入代码：A 股 6 位（如 `600519`）、ETF（如 `510300`）、港股 5 位（如 `00700`）
3. 点击 **查询** 按钮
4. 查看均线推演表格与 K 线图，点击表格任意一行可预览该涨跌幅对应的预测价与均线

> **支持范围**
> - 沪市：`6` / `9` / `5` 开头
> - 深市：`0` / `1` / `3` / `4` / `8` 开头（含 ETF `15` / `51` 开头）
> - 港股：5 位数字（接口会补齐为 5 位并加 `hk` 前缀，如 `hk00700`）
> - 若浏览器对跨域请求有额外限制，建议通过本地服务器访问（见「本地运行」）

## 界面说明

| 区域 | 说明 |
|------|------|
| 输入区 | 输入代码，支持历史自动补全与键盘导航 |
| 状态栏 | 显示股票名称、最新价、当前 MA 值、市场状态（盘中/已收盘）、数据源 |
| 推演表格 | 左表为涨幅（0~+10%），右表为跌幅（-10%~0%），含预测收盘价、关键位与 MA5/10/20 |
| 标注层开关 | 控制 K 线图上的支撑/压力位、斐波那契回撤是否显示 |
| K 线图 | 真实 K 线 + 三条均线，虚线右侧为预测区域；点击标题可折叠 |
| 复制按钮 | 将测算结果导出为纯文本 |

## 技术细节

- **数据接口** — 腾讯 K 线 API：`web.ifzq.gtimg.cn/appstock/app/fqkline/get`
- **均线算法** — 简单移动平均（SMA），取最近 N 日收盘价均值；不足周期返回 `null` 而非误导性数值
- **预测逻辑** — 以「盘中昨收 / 已收盘今收」为基准价施加涨跌幅作为下一交易日收盘价，重新计算 MA5/10/20
- **图表渲染** — 原生 HTML5 Canvas，`devicePixelRatio` 适配，无第三方图表库
- **网络健壮性** — `AbortController` 8 秒超时取消、同代码请求去重、60 秒结果缓存、过期响应丢弃
- **主题切换** — CSS 变量 + `localStorage` 持久化
